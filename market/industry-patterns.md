# Industry Patterns (India fresher hiring, 2026)

Recurring structural patterns that shape all four assets. Labels + confidence inline.

## 1. Evidence beats claims, everywhere
`[FACT, High]` Every credible source — embedded (piestsystems), AI (masaischool/taggd), SWE (glassdoor aggregations) — converges on the same thing: **demonstrated, documented projects on real hardware / shipped to production** outweigh coursework, buzzword lists, and even degree. "2–3 well-documented projects worth more than ten shallow ones." `[INFER, High]` This is the single most important pattern for the portfolio + GitHub strategy.

## 2. Specialization statement at the top
`[FACT, High]` Strong fresher resumes lead with a **specific specialization line**, not a generic title — e.g. "Embedded Engineer with hands-on STM32/FreeRTOS/CAN," not "embedded systems skills." (piestsystems.) `[INFER, High]` Confirms the candidate must resolve his positioning contradiction (documented in the reference-repo audit) into **one** specific line.

## 3. Named tools, not vague categories
`[FACT, High]` Postings and ATS reward **explicit tool names** ("STM32, Keil, FreeRTOS, PCAN, AUTOSAR fundamentals") over "embedded systems." (piestsystems.) `[REC, High]` Skills must be tool-named and each backed by a project bullet — but only tools actually used (truthfulness).

## 4. The DSA gate is real but role-specific
`[FACT, High]` Product-SWE fresher hiring is DSA-gated via timed OAs (Amazon, Flipkart). `[INFER, High]` This gate applies far less to **embedded/hardware** roles, which weight C + hardware projects. Choosing embedding-primary **reduces** exposure to the candidate's weakest area (Basic DSA) while software stays a secondary door.

## 5. India-specific demand drivers
`[FACT, High]` Make-in-India, EV transition, semiconductor PLI, IoT, and Industrial IoT are named repeatedly as multi-year embedded demand drivers; Bangalore is a primary hub (Bosch, Continental, Tata Elxsi, Intel, Qualcomm, TI). (dqindia, networkzsystems, technoscripts.) `[INFER, Medium]` Structural tailwind for an embedded-primary bet through 2027+.

## 6. Internship-to-FTE and project-portfolio entry
`[FACT, High]` AI/ML and many tech tracks hire freshers via internship→PPO and via project portfolios rather than pure exams. (masaischool, acciojob.) `[INFER, High]` The candidate's Nokia + iHelp internships are a genuine credibility anchor; the portfolio's job is to convert internship + project evidence into a coherent story.

## 7. Consistency across channels is itself a signal
`[INFER, High]` Recruiters cross-reference LinkedIn ↔ GitHub ↔ resume ↔ portfolio. Inconsistent headline/dates read as carelessness. (Reinforced by the reference-repo audit, which found exactly this drift.) The four assets must trace to one identity.
