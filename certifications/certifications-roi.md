| Generic "AI/ML" MOOC certificates | **Low** | Recruiters discount unbacked MOOCs; a shipped project beats a certificate |

## 3. The governing rule
`[REC, High]` A certificate is worth pursuing **only when paired with a demonstrable artifact**. A cert with no project is weak signal; a project with no cert is strong signal. Prioritize projects; use certs to formalize skills you can already show. Never let a *planned* cert appear as completed.
