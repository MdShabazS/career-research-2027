# LinkedIn Quality Framework

A four-tier ladder to grade a technical LinkedIn profile, from the brief. Each section is scored to a tier; the profile's tier is roughly its weakest important section.

## The ladder

| Tier | Meaning |
|---|---|
| **Superficial** | Generic; no positioning; buzzwords; no proof. |
| **Acceptable** | Complete, coherent, honest, but plain — no differentiation or metrics. |
| **Strong** | Specific positioning, real metrics, live proof, consistent with other channels. |
| **Elite** | All of Strong + a memorable narrative, genuine engagement/recommendations, and a differentiator that is clearly the person's own. |

## Section-by-section rubric

| Section | Superficial | Acceptable | Strong | Elite |
|---|---|---|---|---|
| **Headline** | "Student" / "Software Engineer" | role + one tech | role + 3–4 named tech + value prop | + memorable, specific differentiator |
| **About** | empty or buzzwords | who/what, honest | hook + depth + 2–3 real metrics + CTA | + distinct voice, coherent story |
| **Experience** | title + dates only | duty description | quantified, honest, ownership clear | + trade-offs/impact framed well |
| **Featured** | empty | one link | repos + portfolio, working | + a project writeup / case study |
| **Skills** | 30+ random | relevant list | grouped, backed, endorsed | + endorsements from real collaborators |
| **Projects/Education/Leadership** | sparse | listed | evidenced, consistent | + reinforces the one identity |
| **Consistency** | contradicts resume | mostly aligns | fully aligned dates/positioning | + each channel adds, none contradicts |

## Credibility signals to engineer (honestly)
`[REC, High]` Real metrics; named tools-in-context; live Featured links; genuine recommendations from internship mentors/teammates; activity that is real (a few substantive posts/comments beat none, but fake engagement is worse than silence).

## Anti-patterns (auto-drop to Superficial)
`[REC, High]` Inflated seniority/experience-years; skills never used; AI-ownership claims beyond the truth; positioning that contradicts the resume/GitHub; buzzword About.
