# Source Index

Every source actually retrieved for this research, classified by the `METHODOLOGY.md` hierarchy. **Honesty note:** most sources are *strong-secondary* (recruiting/career/industry publications) and *supporting* (practitioner/aggregator blogs), cross-checked for agreement. Truly *primary* official sources (Google Cloud, ARM, AUTOSAR, LinkedIn/GitHub docs) were **not** each fetched individually; where their guidance is used it is via secondary summaries and marked accordingly. Direct observations (GitHub API, the reference repo) are the strongest primary evidence here.
