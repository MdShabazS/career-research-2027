# GitHub — Elite Benchmark

What strong engineer GitHub profiles do (2025–2026). GitHub profiles *are* retrievable; patterns below are cross-checked against recruiter guidance rather than asserted from a handful of profiles (see `METHODOLOGY.md`).

## 1. The 11–30 second scan
- `[FACT, High]` Recruiters spend ~11–30 seconds and look at: **pinned repositories, whether projects look real/finished, recent activity, and the profile README.** (instahyre, readmedesign, reskilll.)

## 2. Pinned repositories (the whole ballgame)
- `[FACT, High]` Up to 6 pins; recruiters actually read **2–4** with clean READMEs, real functionality, and ideally live demos. **Quality beats quantity — 3 polished repos beat 40 half-finished ones.** (reskilll, instahyre, readmedesign.)
- `[FACT, High]` Repo naming matters: `react-kanban-board` (good) vs `Final-project-v2-final` (bad). Each repo needs its own README: purpose, setup, stack, decisions. (readmedesign.)

## 3. Profile README
- `[FACT, High]` Treated as an elevator pitch answering: **identity, current goal, concrete capability** — demonstrate impact, don't just list tech. (readmedesign, devbio.)

## 4. Credibility signals vs. ignored metrics
- `[FACT, High]` **Signals:** descriptive commit messages ("Fix header alignment on mobile" not "fix"), presence of **tests and GitHub Actions (CI)**, real documentation, repo topic tags, contact/location in bio. **Ignored/weak:** badge collections, the green contribution-graph quantity, forks-without-contribution. (readmedesign, instahyre, gitshare.)
- `[FACT, High]` Recruiters **don't care about streaks** and know they're gameable — **never fake commits.** (instahyre, gitshare.)

## 5. Elite differentiators
- `[INFER, High]` Architecture docs/diagrams, screenshots/GIFs of the thing working, a live demo link, meaningful issues/PRs/releases, and reproducibility (a README a stranger can run). A real open-source contribution, however small, outranks a wall of solo toy repos.
