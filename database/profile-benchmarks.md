# Profile Benchmarks — consolidated tier ladders

One place to see the four asset quality ladders side by side. Details in each asset folder.

## Resume (see `../resume/scoring-framework.md`)
Rework (<60) → Acceptable (60–74) → Strong (75–89) → Elite-for-fresher (90–100). Gate: truthfulness + no PII leak.

## LinkedIn (see `../linkedin/linkedin-framework.md`)
Superficial → Acceptable → Strong → Elite. Tier ≈ weakest important section. Elite needs a differentiator + a real recommendation + a Featured writeup.

## GitHub (see `../github/github-quality-framework.md`)
Superficial → Acceptable → Strong → Elite. Tier ≈ tier of the pinned repos. Elite needs CI + one real OSS contribution.

## Portfolio (see `../portfolio/`)
Template (motion, no meaning) → Functional (real content, working links) → Strong (restrained 3D that explains the work) → Premium engineering product (one signature interaction, fast, accessible, evidence-led). High-end ≠ max animation.

## Project (see `../projects/project-quality-framework.md`)
Tutorial → Demonstration → Strong portfolio → Industry-credible.

## Candidate's realistic near-term targets
`[REC, Medium]` Resume **Strong**; LinkedIn **Strong**; GitHub **Strong** (Elite after CI+OSS); Portfolio **Strong→Premium** once demo media + one signature interaction exist; Projects: 2 already **Strong**, aim for 1 **Industry-credible** (BCM + tests/CI/diagram).
