# Job Requirements — extracted by role family

Consolidated fresher/junior requirements (India, 2026) from the market research. `[FACT]` unless noted. "Candidate coverage" cross-checks the reference repo.

## Embedded Software / Systems (fresher)
- **Required:** Embedded C; MCU (STM32/ESP32); GPIO/timers/interrupts/ADC/PWM; **UART/SPI/I2C**; debugging; Git; testing; 2–3 real-hardware projects.
- **Preferred:** FreeRTOS; JTAG/SWD; C++; embedded Linux (role-dependent).
- **Candidate coverage:** Embedded C ✓, MCU ✓, I2C/ADC/timers ✓, projects ✓ | UART/SPI ✗, RTOS ✗, JTAG ✗. → **strong entry fit, closeable gaps.**
- Source: piestsystems, ziprecruiter, careers360.

## Automotive Embedded (fresher)
- **Required:** Embedded C; **CAN/LIN**; **AUTOSAR** fundamentals; UDS/diagnostics; STM32/Keil; FreeRTOS; HIL awareness; ISO 26262/MISRA awareness.
- **Candidate coverage:** automotive *theme* (BCM) ✓ | CAN ✗, AUTOSAR ✗, safety ✗. → **gated; aspirational, not current.**
- Source: piestsystems, careers360/skill-lync, placementindia.

## Software Engineer (fresher, product)
- **Required:** **DSA + timed OA**; one strong language; Git; OOP; DBMS/SQL; OS; CN; a stack (Python/JS/React) + projects.
- **Candidate coverage:** projects ✓, Python ✓ (Basic) | DSA Basic ✗ (the gate). → **secondary door; DSA-limited.**
- Source: glassdoor, apna, shashiworks.

## AI/ML Engineer (applied, fresher)
- **Required:** Python; 2–3 **shipped** ML projects; problem-solving; deployment ("not just a notebook"); increasingly **RAG/vector DB**.
- **Candidate coverage:** VisionPay ✓, skin-disease demo ✓ | deployment/RAG ✗, skills Basic. → **supporting differentiator, not standalone headline.**
- Source: taggd, acciojob, masaischool.

## GCP / Cloud (fresher)
- **Required:** Python-for-infra; Linux; networking; **Docker/K8s/Terraform**; a real cloud project; cert ladder (Digital Leader → ACE).
- **Candidate coverage:** 1 GenAI virtual-internship cert only | no cloud project, no container/IaC. → **weakest fit; defer.**
- Source: futurense, cloudsoftsol, internshala.

## Cross-family common core
`[INFER, High]` C/one strong language, Git, testing, and demonstrable projects recur in **every** family. That shared base is the safest early investment regardless of final positioning.
