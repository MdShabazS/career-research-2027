# Final Profile Strategy

The one coherent professional identity the four assets should express, and how they reinforce it without being identical. This is the capstone of the research; it is a `RECOMMENDATION` built on everything in this repo.

## 1. Strongest positioning (the decision)
`[REC, High]` **Embedded Software Engineer, with on-device intelligence as the differentiator.**

Why this and not the alternatives:
- **Embedded-primary** is where the candidate's *demonstrable evidence* is densest (2 real hardware projects), it matches the ECE degree, and it sits in a structurally growing India market. It also **routes around his weakest area** (Basic DSA, the SWE gate).
- **On-device CV** (VisionPay, MITRA) is a genuine, rare-for-a-fresher differentiator — it makes him "the embedded person who also does edge-AI," not a generic embedded fresher.
- **Not "Automotive Embedded" as the headline:** that segment is gated by CAN/AUTOSAR/ISO 26262, none of which he can truthfully claim yet. Automotive is the **aspirational vector** (his BCM project points at it) — earned later with a CAN build, not asserted now.
- **Not "Software Engineer" as the headline:** credible as a *secondary* door, but DSA-gated and less evidenced than embedded.
- **Not "GCP/Cloud":** the least-evidenced, least ECE-adjacent option; a possible year-2 pivot, not a 2027 identity.

This is deliberately **not** a rubber-stamp of either positioning currently in the reference repo (canonical "Software\|Embedded" nor the resume's "Embedded\|Automotive"). The evidence points to **Embedded Software + on-device CV**, with automotive as growth and software as a secondary door.

## 2. Strongest role family & skill combination
`[REC, High]` Role family: **Embedded Software / Embedded Systems (IoT-leaning), Bangalore.** Skill combination that creates employability: **Strong C + MCU peripherals + UART/SPI/I2C + FreeRTOS + debugging + Git/testing**, layered with **OpenCV/TFLite on-device CV**. That combination is both in-demand and largely already started.

## 3. Strongest project themes
`[REC, High]` Two themes, both already seeded: **(a) real-time MCU firmware** (BCM, Smart Wellness) and **(b) on-device vision** (VisionPay). Next builds extend a + join a×b: a FreeRTOS port, a UART/SPI multi-sensor node, and — the signature move — an **edge-AI-on-MCU** demo (e.g. TFLite-Micro on an MCU) that fuses both themes into one flagship.

## 4. Strongest evidence strategy
`[REC, High]` Evidence over claims, everywhere: documented repos with real media and demo videos; honest metrics only; truthful status labels; the portfolio's 3D used to *show mechanisms*, not decorate. Fix the integrity leaks (Nokia tense, plaintext phone, empty AEGIS repo) — because with a truthfulness-first identity, any discovered inconsistency is disproportionately damaging.

## 5. How the four assets reinforce one story (same story, different depth)

```
                 ONE IDENTITY
   "Embedded Software Engineer · on-device intelligence"
                      │
   ┌───────────┬──────┴───────┬──────────────┐
 RESUME      LINKEDIN        GITHUB        PORTFOLIO
 1 page,     narrative +     the proof     the experience
 scannable   network         (code+docs)   (interactive)
 evidence    discovery
```

- **Resume** = the compressed, ATS-safe evidence sheet. Same headline, top-3 projects, honest metrics.
- **LinkedIn** = the same identity told as a first-person narrative for recruiter discovery; Featured links to GitHub/portfolio. Adds voice, not new facts.
- **GitHub** = the primary proof layer: the repos the resume/LinkedIn/portfolio all point to. Adds depth (code, READMEs, diagrams), not new claims.
- **Portfolio** = the immersive rendering of the same projects, where 3D makes the engineering legible. Adds experience, not new facts.

`[REC, High]` **Rule:** each asset may add *depth* the others lack, but none may introduce a skill, project, title, metric, or date the others contradict. Consistency across the four is itself a hiring signal (and the exact thing the reference-repo audit found broken).

That coherence, on genuine evidence, is the strongest realistic position for this candidate.
